# frogworks404 サイト デザイン指示（Figma AI用）

## プロジェクト概要

個人制作・実験の記録サイト「frogworks404」のUIデザイン。
ポートフォリオではなく**サークルの活動記録**というコンセプト。
完成品の陳列ではなく、進行中・アイデア・試行錯誤を含む記録としての建付け。

---

## デザイントークン（厳守）

### カラー
| トークン名 | 値 | 用途 |
|---|---|---|
| paper | #e8e8e8 | ページ背景 |
| ink | #1a1a1e | メインテキスト・ボーダー |
| ink-mid | #525260 | サブテキスト・説明文 |
| ink-faint | #9898a8 | 日付・ラベル・薄いテキスト |
| rule | rgba(40,50,100,0.15) | 区切り線・ボーダー |
| grid-color | rgba(40,80,200,0.07) | 方眼グリッド線（背景テクスチャ） |
| margin-red | #a03030 | ページ左端の縦線のみ |
| blue-label | #1e3a7a | build-logバッジのテキスト |
| cover-bg | #111118 | 黒ボックスヘッダーの背景 |

### タイポグラフィ
| 用途 | フォント | ウェイト |
|---|---|---|
| 本文・見出し | BIZ UDPGothic | 400 / 700 |
| 日付・ラベル・バッジ・コード | JetBrains Mono | 400 / 600 |

### スペーシング・レイアウト
- コンテンツ最大幅：700px、中央寄せ
- 方眼グリッド：20px ピッチ
- ページ左端：赤い縦線（2px、#a03030）+ 左パディング 48px
- セクション間区切り：2px solid #1a1a1e（太め）
- エントリ間区切り：1px solid rgba(40,50,100,0.15)（細め）

### 背景テクスチャ
紙面全体に薄い青の方眼グリッド（rgba(40,80,200,0.07)、20pxピッチ）を適用。
主張せず、質感として機能させる。

### バッジ（タグ）スタイル
JetBrains Mono 10px、border 1px solid currentColor、padding 2px 7px、背景なし。
色はテキスト色のみで差別化：
- build-log：#1e3a7a
- software：#525260
- idea：#a03030
- note：#525260
- wip：#9898a8

## ページ別指示

---

### 1. TOP（フィードページ）

**役割：** サイトの入口。全エントリを時系列で表示し、タグで絞り込める。

**ヘッダー構成（上から）：**

①黒ボックス（cover-box）
- 背景 #111118、内部にも同じ青方眼グリッドを薄く適用
- 上部：eyebrow テキスト「制作・実験記録 ／ Activity Log」（JetBrains Mono 10px、rgba(255,255,255,0.35)、letter-spacing広め）
- タイトル「frogworks404」（BIZ UDPGothic 40px Bold、白、letter-spacing -0.02em）
- 細い区切り線（rgba(255,255,255,0.12)）
- 説明文「ソフトウェア・ハードウェア・アイデアの記録」（12px、rgba(255,255,255,0.38)）

②メタ情報テーブル（黒ボックス直下、paper色背景）
- 3カラムのボーダー付きグリッド表
- 各セル：ラベル（JetBrains Mono 10px、ink-faint）＋ 値（JetBrains Mono 12px Bold、ink）
- 項目：記録開始 / エントリ数 / 最終更新

③ヘッダー全体の下部：2px solid ink のボーダー

**フィルターバー：**
- 「FILTER —」ラベル（JetBrains Mono 10px、ink-faint）
- チップボタン：すべて / build-log / software / idea / note（バッジと同じスタイル）
- アクティブ状態：背景 ink、テキスト paper に反転

**セクション区切り：**
- JetBrains Mono 10px、ink-faint、右側に細い横線が伸びる（「最新の記録 ————」スタイル）

**エントリカード（繰り返し）：**
- 上下パディング 28px、下部に rule カラーの区切り線
- 1行目：日付（JetBrains Mono 11px、ink-faint）＋ バッジ群
- タイトル（BIZ UDPGothic 20px Bold、ink）
- 本文プレビュー（14px、ink-mid、最大3行）
- WIPエントリのみ：進捗バー（幅72px、高さ2px、背景rule、塗りink）＋ 進捗テキスト（JetBrains Mono 10px、ink-faint）

**フッター：**
- 2px solid ink の上ボーダー
- 左：「frogworks404 © 2024–」（JetBrains Mono 11px、ink-faint）
- 右：GitHub / X / about リンク（JetBrains Mono 11px、ink-mid）

---

### 2. エントリ詳細 A（記事・アイデア型）

**役割：** 文章主体の記事・コンセプトメモ・アイデアのための読み物ページ。

**ヘッダー：**
- TOPと共通のサイトヘッダーは省略し、左上に「← frogworks404」の戻りリンク（JetBrains Mono 11px、ink-mid）
- 記事タイトル（BIZ UDPGothic 28px Bold、ink）
- メタ行：日付 ＋ バッジ（TOPと同スタイル）
- 2px solid ink のボーダーで本文エリアと区切る

**本文エリア：**
- 最大幅 600px
- 本文（BIZ UDPGothic 15px、ink-mid、line-height 1.9）
- 見出し H2（BIZ UDPGothic 18px Bold、ink）
- 見出し H3（BIZ UDPGothic 15px Bold、ink）
- コードブロック：背景 #1a1a1e、テキスト #e8e8e8、JetBrains Mono 13px、パディング 16px
- 引用ブロック：左に 3px solid rule のボーダー、テキスト ink-mid
- 画像：幅100%、下部キャプション（JetBrains Mono 10px、ink-faint）

**フッター：**
- 記事末尾：「← 記録一覧に戻る」リンク
- TOPと共通のフッター

---

### 3. エントリ詳細 B（プロダクト・LP型）

**役割：** 個別プロダクトの紹介ページ。LP的な構成でプロダクトの価値を伝える。
Alpine.jsによるスクロールアニメーション（x-intersect）で各セクションがフェードインする前提でデザイン。

**構成（上から）：**

①ヒーローセクション
- 黒ボックス（TOPのcover-boxと同スタイル）をページ上部に大きく配置
- プロダクト名（40px Bold、白）
- キャッチコピー（16px、rgba(255,255,255,0.6)）
- CTAボタン：アウトライン白ボタン（JetBrains Mono 12px）
- プロダクト画像またはスクリーンショットをボックス内右側またはボックス直下に配置

②ステータスバー
- メタ情報テーブル（TOPのheader-tableと同スタイル）
- 項目：バージョン / ステータス / ライセンス / リリース日

③特徴セクション（繰り返し）
- セクション区切り（「— FEATURES」スタイル）
- 特徴ごとにアイコン or ASCII的なシンボル + 見出し + 説明テキストのカード
- 各カードはエントリカードと同系統のスタイル（下ボーダー）

④スクリーンショット・デモセクション
- 幅広の画像エリア（最大幅 700px）
- キャプション付き

⑤リンクセクション
- GitHub / App Store / BOOTH など
- JetBrains Mono スタイルのリンクリスト

⑥記録・更新ログ（オプション）
- エントリ A スタイルの小さい変更履歴

### 4. プロジェクト一覧

**役割：** 全プロジェクトをカテゴリ・ステータス別に俯瞰できるページ。

**ヘッダー：**
- ページタイトル「プロジェクト一覧」（28px Bold）
- サブテキスト「進行中・完成・アイデア段階を含む全プロジェクト」
- 2px solid ink のボーダー

**フィルター：**
- TOPと同様のタグフィルターチップ

**プロジェクトカード（グリッドまたはリスト）：**

リスト表示を基本とする（TOPのエントリカードより情報密度を上げる）：
- プロジェクト名（BIZ UDPGothic 18px Bold）
- 1行説明（14px、ink-mid）
- バッジ群 ＋ 進捗バー（WIPのみ）
- リンクアイコン：GitHub / App / BOOTH（JetBrains Mono 10px）

**ステータスグループ分け（オプション）：**
- 「— 進行中」「— 完成」「— アイデア」でセクション区切りを入れる構成も可

---

### 5. About

**役割：** frogworks404が何者かを最小限で伝えるページ。自己紹介的にならない。

**構成：**

①黒ボックス（TOPのcover-boxをやや小さく）
- 「frogworks404 について」の eyebrow テキスト
- 一言説明文（白、16px）

②本文（エントリAの本文スタイルと同じ）
- 何を作っているか（リスト形式）
- 使っている主な技術・ツール（バッジ的に並べる）
- 連絡先・リンク（GitHub / X / BOOTH）

③「最近の記録」セクション
- TOPフィードから最新3件を小さくリスト表示
- 「すべての記録を見る →」リンク

## 共通ルール

- 全ページに左端の赤い縦線（2px solid #a03030）を継続
- 背景の青方眼グリッドは全ページ共通
- ナビゲーションバーは設けない。ページ間移動は文脈内のテキストリンクのみ
- 角丸（border-radius）は使わない
- 影（box-shadow）は使わない
- アイコンは使わない（テキストとバッジで代替）
- 装飾的な要素は入れない。余白と線とタイポグラフィだけで構成する
