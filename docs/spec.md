# frog404.work デザイン仕様 v1

この文書は、frog404.work（Zola + Fubako）のリデザインの決定事項と、その理由をまとめたものです。実装時の判断基準として使ってください。

- 値は `_tokens.scss` にあります。ここに書いていない色・サイズ・時間を新しく作らないでください。必要になったら、追加する前に相談してください。
- 見た目の正解は `mocks/` にあります。ただし構造はそのまま写さないでください（理由は `mocks/README.md`）。
- 作業の順番と完了条件は `tasks.md` にあります。
- 「§」付きの番号は、この文書内の節を指します。

---

## 1. コンセプト

**「工学ノート／製図用紙」**。サイトは制作・実験の記録帳です。

| 要素 | 見立て |
|---|---|
| 背景の方眼 | 製図用紙。32pxの細線と、4マスごとの交点に置く十字 |
| 墨のサイドバー（PC）／ヘッダー（モバイル） | ノートの**綴じ**。PCは左綴じ、モバイルは上綴じ |
| 表題欄（トップ・記事の冒頭） | 図面の表題欄。記事1本＝図面1枚 |
| 奥付（ページ末） | 本の奥付。表題欄と上下で紙面を挟む |
| 「図版なし」の札 | 製図のハッチング（斜線） |

- **読者**：エンジニアとメイカー。
- **レトロ感の出し方**：紙の色、墨、組版で出します。ノイズ、走査線、ピクセルフォントなどの「効果」では出しません。
- **装飾の判断基準**：迷ったら「製図・技術書・帳簿にあるか」で判断してください。

## 2. 色

使える色は `_tokens.scss` の色だけです。

| 役割 | トークン | 使う場所 |
|---|---|---|
| 紙 | `--c-paper` | ページの地。箱の塗り |
| 墨 | `--c-ink` | 本文、綴じ、墨ベタの帯、強い罫線、選択中のタグ |
| 朱 | `--c-vermilion` | リンク、ステータス印（`IN SERVICE`など）、見出し番号、タグ名（一覧） |
| 朱（墨の上） | `--c-vermilion-on-ink` | サイドバーとメニューの現在地 |
| 補助の文字 | `--c-text-sub` / `--c-text-muted` / `--c-text-disabled` | 抜粋、メタ情報、無効な状態 |

**色の使い方の規則**

- **カテゴリに色を割り当てない。** タグはすべて同じ見た目にします。
- **朱は「リンク」と「状態の小さな印」だけに使う。** 面を朱で塗りません。
- **選択中の状態は墨ベタで示す**（例：選択中のタグ）。
- 十字だけは青系（`#2B4C7E`、32%）にします。製図の青焼きへの目配せです。値は `assets/grid-cross.svg` に入っています。
- ダークモードは作りません（v1の範囲外）。

## 3. 書体と組版

### 3.1 書体の役割

| 書体 | 役割 | ウェイト |
|---|---|---|
| Shippori Mincho B1 | **人が書いた文章**。本文・見出し・ナビ・抜粋 | 400 / 500 / 700 |
| IBM Plex Mono | **機械が付けた情報**。日付・番号・タグ・ラベル・件数・コード | 400 / 500 / 600 |

**書体の規則**

- **ゴシック体は使いません。**
- **Mono は英数字専用です。** Mono のフォントには仮名と漢字が含まれないため、日本語のラベルは明朝で書きます。
- 読み込みは Google Fonts の `css2`（`display=swap`）で、上のウェイトだけに絞ります。

### 3.2 文字サイズと行送り（PC）

行送りは必ず32pxの倍数にします（§4.2）。

| 用途 | 書体 | サイズ／行送り |
|---|---|---|
| ページ見出し（記録一覧） | 明朝 700 | 32 / 48 |
| 記事タイトル（表題欄の中） | 明朝 700 | 28 / 48（2行で96） |
| 表題欄のステートメント | 明朝 700 | 24 / 32 |
| 区画見出し | 明朝 700 | 22 / 30（32の箱に下線2pxを含む） |
| カードの題、最新記事の題、記事の小見出し | 明朝 700 | 20 / 32 |
| 一覧の行の題 | 明朝 700 | 18 / 32 |
| **記事本文** | 明朝 500 | **17 / 32** |
| カードの説明 | 明朝 500 | 16 / 32 |
| 抜粋 | 明朝 500 | 15 / 32 |
| 注、キャプション、目次 | 明朝 | 14 / 32 |
| メタ情報（日付など） | Mono | 14 |
| ラベル、タグ | Mono | 12 |
| 墨の帯の中の大文字ラベル（`SHEET 404` など） | Mono | 11、字間 0.2em |

**最小サイズ**：明朝は14px、Mono は12px です。墨の帯の中の大文字ラベルだけは11pxを例外として認めます。

**モバイル**：基本は同じで、次の箇所だけ下げます。本文16、記事タイトル21／32、区画見出し20、ページ見出し28。

### 3.3 組版の規則

| 対象 | 規則 |
|---|---|
| 記事本文 | 両端揃え。段落の頭は1字下げ（`text-indent: 1em`）。段落の間は空けない。`line-break: strict` |
| リード段落 | 1字下げなし |
| 見出し | `font-feature-settings: "palt"`、`word-break: auto-phrase`、`text-wrap: balance` |
| カードの説明・抜粋 | **左揃え**。英単語が混ざると、両端揃えは字間が崩れるため |
| 全体 | `text-autospace: normal`（和文と欧文の間の自動アキ。対応ブラウザだけで効く段階的な強化） |
| 長いタイトル | 決めた行数で打ち切る（`-webkit-line-clamp`） |

## 4. グリッド（最重要）

### 4.1 単位

| 名前 | 値 | 用途 |
|---|---|---|
| G | 32px | 方眼1マス。本文の行送り。部品の高さと部品間の間隔はこの倍数 |
| u | 8px | 部品の**内側**の余白 |
| 主線 | 128px（4G） | 十字を置く間隔。大きな区切りの位置合わせに使う |

### 4.2 守ること

1. **文字の行は、すべて方眼の行（32px）に乗せる。** 行送りは32の倍数にし、ブロックの高さも32の倍数にします。枠線は `box-sizing: border-box` で内側に含めます。
2. **区画の見出しは「見出しの行＋その下に引く下線」にする。** 下線（2px、墨）は**十字の並ぶ行**に揃えます。
3. **方眼を紙色で塗って隠さない。** 方眼の上に不透明な面を置いてよいのは、**表題欄、奥付、図版、コード、注の囲み、関連製作物の札、タグ**だけです。それ以外の文字は方眼の上に直接置きます。
4. **中央寄せで、方眼からずれる配置をしない。** 例：記事本文の段を中央に置く。
5. **横の基準は本文の左端。** 方眼の原点を、本文の段（PC は 832px の main）の左端に合わせます。

### 4.3 背景の実装

`_tokens.scss` の `grid-paper($x, $y)` を使います。

- **PC**：`$x` は main の左端の x 座標です（`(100vw − 1152px) / 2 + 256 + 64`）。`$y = 64px` にすると、十字は y = 64 + 128n の行に並びます。トップの区画の下線（y = 320, 832）がこの行に乗ります。
- **モバイル**：本文の段の幅を `round(down, 100vw − 32px, 32px)` で32の倍数に丸めて中央に置き、方眼の x をその左端に合わせます。`round()` に対応していないブラウザでは、`width: calc(100vw - 38px)` を代わりに使います。
- `round()` で丸める理由：丸めないと、文字と方眼の線が数pxずれて、方眼がただの柄に見えてしまうためです。

## 5. レイアウト

### 5.1 PC（ビューポート1216px以上）

```
|— 余白（方眼） —|綴じ 256|間 64|main 832|— 余白（方眼） —|
                └────── 1152px を中央寄せ ──────┘
```

**綴じ（サイドバー）**
- 墨ベタで、高さはページ全体です。右端に朱の線（2px）を引きます。
- 中身は上から：ロゴ（Mono 600）／PAGES（記録一覧・製作物・About）／LINKS（GitHub・X、下端に寄せる）。
- 現在地は、文字を `--c-vermilion-on-ink` にし、左に2pxの縦線を付けます（`aria-current="page"`）。

**main**
- 上の余白は64pxです。
- カードの段組は 256 × 3 列、列の間は32px です。
- 記事ページは「本文 576 ＋ 間 32 ＋ 傍注 224」です。**傍注の段は常に表示します**（目次は全記事に入るため）。

### 5.2 モバイル（ビューポート1216px未満）

- **ヘッダー（上の綴じ）**：高さ64、墨ベタ、下端に朱の線2px。左にロゴ、右にページコード（Mono 12：`INDEX`、`No.019`など）と MENU ボタン（88×44）。
- **本文の段**：§4.3の幅（390px幅の端末なら352px）。
- 1216px未満の中間の幅（タブレット）は個別に設計していません（§12）。暫定として、モバイルのレイアウトを本文の段の最大幅704pxで使ってください。

## 7. ページ構成

各ページの中身を上から順に並べます。

| ページ | PC | モバイル |
|---|---|---|
| **トップ** | 表題欄 → 01 製作物（カード3枚） → 02 最新の記録（タグ → 最新記事 → 台帳3件） → 奥付 | 同じ順番で縦に積む |
| **記事一覧** | ページ見出し（パンくず `SHEET 404 / INDEX`、`記録一覧`、`019 / 019 ENTRIES`、説明）＋下線 → タグ（件数付き） → **全件を1ページに並べる**（ページ送りなし） → `END OF INDEX — 019 ENTRIES` → 奥付 | 同じ |
| **記事詳細** | 表題欄 → 本文576＋傍注224（目次・注・関連製作物） → 前後の記録 → 奥付 | 表題欄 → 目次 → 本文（注は囲み） → 関連製作物 → 前後の記録 → 奥付 |

**記事数が60件を超えた場合**（一覧）：最初の50件を表示し、`すべて表示（N件）` ボタンで残りを出します。番号付きのページ送りは使いません。

## 8. コンテンツとデータ（Zola）

| 表示するもの | データの出どころ |
|---|---|
| 記録番号 `No.019` | `extra.no`。未設定なら投稿順で採番する。どちらにするかは §12 |
| 抜粋 | `description`（未設定なら `page.summary`） |
| 図版 | `extra.image`。なければ図版なしの札 |
| 関連製作物の札・表題欄の PROJECT | `extra.project = "halfgrip"` → `get_page(path="projects/halfgrip/index.md")` で名前・ステータス・説明を引く。**説明は製作物ページを正本にする** |
| ステータス | 製作物ページの `extra.status`（`in-service` / `prototype`） |
| 目次 | `page.toc` |
| READ（読了時間） | `page.reading_time` |
| REV.（記事） | `page.updated`。なければ `—` |
| ENTRIES / SINCE / REV.（サイト全体） | 記録のセクションのページ数、最古の日付、最新の日付 |
| タグの件数 | `get_taxonomy(kind="tags")` |
| 最新記事（トップ） | 記録のセクションの先頭1件 |
| 傍注 | 本文のショートコード `{% note() %}…{% end %}`。番号はショートコードの `nth` を使う |

**傍注の実装**
- HTML 上は、段落の直後に `<aside class="note">` を出します。
- PC では float と負のマージンで傍注の段へはみ出させます（Tufte CSS 方式）。JS は使いません。
- モバイルでは本文の中の囲みとして表示します。
- 運用ルールとして、注は短く書きます。長い注や、注が連続すると、重なったり縦にずれたりするためです。

## 9. モーション：「作図はコマ打ちで」

### 9.1 原則

1. **作図の順番で出す**：罫線と枠 → 墨の帯・番号 → 見出し → 本文 → 図版。
2. **コマ打ちにする**：なめらかな補間は使わず、`steps(n, end)` で動かします。1コマ = `--f`（83ms、12fps）。大きな動きだけ `--f-heavy`（125ms）を使います。
3. **動いたら止める**：ループ、常に動き続ける装飾、パララックスは使いません。
4. **読書を邪魔しない**：本文の段落は動かしません。スクロールに合わせたフェードインはしません。ページを開いたときの演出は、画面の最初の範囲だけに限り、合計8コマ以内に収めます。

### 9.2 動きの一覧

| 名前 | 対象 | 動き | 時間 |
|---|---|---|---|
| 表題欄の作図 | トップと記事の表題欄。ページを開いたときに1回 | 上辺・左辺を引く（scaleX/Y、steps(4)、f0–3）→ 下辺・右辺（f2–5）→ 仕切り線（steps(3)、f4–6）→ 墨の帯（steps(2)、f4–5）→ 見出しを左から現す（`clip-path`、steps(4)、f4–7）→ 項目・罫（f5–7）→ ENTRIES を `000→003→006→010→013→016→019`（f4から1コマごと） | 8コマ |
| 図版の焼き付け | 全図版 | 読み込み中は斜線の札（`LOADING FIG.`）を出し、`load` イベントで画像を opacity 0→1、steps(3)。並んだ図版は2コマずつずらす | 3コマ |
| メニューを開く | モバイル | 墨の面が上から下りる（`clip-path: inset(0 0 100% 0)` → `inset(0)`、steps(4)、500ms）→ INDEX の各行を1コマずつ（500ms + i × 83ms）、steps(1) で出す | 約830ms |
| メニューを閉じる | モバイル | 開くときの逆順（未試作。項目を同時に消す → 面を steps(4) で上げる） | 4コマ |
| リンクに乗せる | リンク | 下線を1pxから2pxに即座に切り替える | 1コマ |
| ボタンを押す | ボタン | `:active` で1px沈む | — |
| カード・行に乗せる | カード、一覧の行 | 図版の枠を墨に変え、題に下線（背景グラデーションの幅を0→100%、steps(3)） | 3コマ |

### 9.3 守ること

- `prefers-reduced-motion: reduce` のときは、すべてのアニメーションとトランジションを無効にします（`_tokens.scss` に記述済み）。
- **JS が動かなくても内容は見える状態にする。** アニメーションは CSS の `animation-fill-mode: both` で付けます。JS が必要なのはカウンターと図版の `load` 検知だけです。JS がない場合は最終状態を表示します。
- 表題欄の作図は、同じセッション内で2回目以降に表示するときは省略してよいです（`sessionStorage` が使えなくても壊れないようにする）。

## 10. アクセシビリティ

- **コントラスト**：本文とラベルは4.5:1以上。朱 `#B5391F` は紙の上で基準を満たします。墨の上では `--c-vermilion-on-ink` を使います。
- **フォーカス**：`:focus-visible` に `outline: 2px solid var(--c-vermilion); outline-offset: 2px`。墨の上では `--c-vermilion-on-ink` にします（モックにはありません）。
- **タップ領域**：44px以上。
- **メニュー**：`aria-expanded` と `aria-controls` を付けます。開いている間は背後のページを操作できないようにし（`inert`）、Esc で閉じ、閉じたら MENU ボタンにフォーカスを戻します。
- **現在地**：`aria-current="page"`。
- **装飾**：方眼、斜線、十字は背景画像なので、読み上げの対象にはなりません。

## 11. やらないこと

- 中央寄せなどで、方眼からずれる配置。
- 要素を何でも箱で囲むこと（箱を使ってよい部品は §4.2-3 に限定）。
- 方眼を紙色で塗って文字の背後だけ消すこと。
- カテゴリに色を割り当てること。朱で面を塗ること。
- ゴシック体。Mono で日本語を表示すること。
- 影、角丸、グラデーションによる面の表現、カードを浮かせる動き。
- ループするアニメーション、パララックス、スクロールに合わせたフェードイン。
- 番号付きのページ送り。
- 年の見出し行（一覧）。
