HalfGrip 筐体の汎用化：
固定部と可変部をどう分けるか

1対象機種をどう決めたか 2肉厚をどう決めたか

HalfGripは、スマートフォンにミラーレスカメラのような操作感を足すためのグリップです。最初の試作は手元の1機種に合わせて作りましたが、ほかの機種でも使えるようにするには、筐体のどこを共通にし、どこを機種ごとに作り分けるかを決める必要がありました。

1対象機種をどう決めたか

対象を広げるほど、吸収しなければならない寸法の幅も広がります。全機種に対応するのではなく、本体の幅と厚みが近い機種をまとめて、ひとつの筐体で受けられる範囲を先に決めました。

幅の違いは可変部で吸収し、ボタンやダイヤルを載せる部分は固定部として共通にします。操作系の位置が機種ごとに変わると、手が覚えた位置が使えなくなるからです。

NOTE 1

対象にした機種の一覧と寸法は、記事末尾の表にまとめています。

2肉厚をどう決めたか

3Dプリントの筐体は、薄くすると軽くなる代わりに、ネジ止め部分や爪の根元から割れやすくなります。負荷のかかる場所だけを厚くし、それ以外は薄くする方針で調整しました。

// enclosure.scad（値は仮）
wall      = 2.0;  // 外壁
wall_boss = 3.2;  // ネジ止め部
clip_root = 2.4;  // 爪の根元

次は、可変部の調整範囲を実機で確かめます。結果は次の記録で報告します。
